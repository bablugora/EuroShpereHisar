Deployment
1. Upload the contents of the "ES Hisar" folder to the same website hosting root, preserving existing files.
2. Ensure the "learn" folder is uploaded as a subfolder so the app opens at https://YOUR-DOMAIN/learn/
3. Test the home page and /learn/ path after deployment.

Important notes
- The supplied website is a static HTML site, so this integration adds the app as a same-domain subfolder and adds navigation links.
- This does not yet unify website accounts with app accounts. The app's current auth/progress is browser-local demo functionality.
- Do not upload secrets, private keys, or student data.
- Keep a backup of the live website before replacing files.
